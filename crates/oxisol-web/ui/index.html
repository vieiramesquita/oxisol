Oxisol HTTP/JSON API

Oxisol Studio embeds an Axum REST API inside the single compiled Rust binary. Automate scenarios from Python, R, Julia, or GIS pipelines on local machines or remote high-performance servers over SSH tunnels.

GET/api/healthLiveness & version check
GET/api/systemHost CPU count, CellState L1d bytes & attached grid
GET/api/presets6 calibrated ecosystem presets (EN/PT-BR)
POST/api/simulateSingle-cell scenario trajectory + mass balance audit
POST/api/grid/runLock-free multi-core spatial grid execution
GET/api/lulc/schemesMapBiomas & ESA WorldCover LULC schemes
POST/api/lulc/runSpatial LULC + modeled climate GeoTIFF/COG engine (terrio)

Quick Python Example

import requests

preset = requests.get("http://127.0.0.1:8080/api/presets").json()[1]["defaults"]
preset["years"] = 100
preset["co2_end_ppm"] = 560.0

res = requests.post("http://127.0.0.1:8080/api/simulate", json=preset).json()
print("Final SOMSC:", res["final_pools"]["somsc"], "g C/m2")
print("Mass Balance Err:", res["final_pools"]["max_mass_balance_err"])

Architecture & Documentation

Running Remotely on Modern High-Performance Servers

# Compile natively with host SIMD (AVX2 / AVX-512 / NEON)
RUSTFLAGS="-C target-cpu=native" cargo build --release -p oxisol-cli

# Launch headless Studio on your server with a spatial grid mounted
./target/release/oxisol serve --host 127.0.0.1 --port 8080 --data-dir /data/grid

# Access securely from your laptop via SSH tunnel
ssh -L 8080:127.0.0.1:8080 user@hpc-server

Full scientific documentation (mdBook) lives in docs/src/ and API reference builds via cargo doc --workspace --no-deps. Released under the MIT License.
